# Changelog

A version section is `## X.Y.Z [release]` (or `[beta]`, `[alpha]`). The release workflow sends that text and type to CurseForge.

## 0.7.1 [release]
- Race voices: 9 races x 2 bodies x 74 toots + 5 Artifact toots (1337)
- Rarity: Poor to Legendary (1 in 500), Artifact (1 in 5000)
- Classic tier: the 14 original toots in every voice, 1 in 200
- Same toot for everyone near you (hidden addon messages: group, guild, /say in instances)
- One toot per person at a time (min 1 s)
- 34 achievements + secret ones, toasts, 15 reward emotes
- Collection: one page per voice, click = replay
- Board: Most heard + Top listener (/wind board off)
- Heard count
- Fart button
- Random farts: ON by default, about 1 per hour + wake-up fart (/wind random off)
- Fart log + changelog in Options
- New: /wind ach, random, board, wait, pair
- Removed: /wind test
